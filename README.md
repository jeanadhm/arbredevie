# ONG Arbre de Vie des Enfants

Site institutionnel de l'Orphelinat Arbre de Vie des Enfants (OAVE), à
Klouékanmè au Bénin.

## Aperçu local

Servir le dossier dist avec un serveur HTTP statique, puis ouvrir la racine.

## Déploiement Vercel

Le fichier vercel.json configure dist comme dossier de sortie. Aucun build
ni variable d'environnement n'est nécessaire.

1. Importer ce dépôt GitHub dans Vercel.
2. Laisser le framework sur Other.
3. Vercel utilisera automatiquement dist comme Output Directory.

Après l'attribution du domaine définitif, ajouter ce domaine dans un sitemap et
dans les métadonnées canoniques.
